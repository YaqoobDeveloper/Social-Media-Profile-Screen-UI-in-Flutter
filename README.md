# Social Media Profile Screen UI in Flutter 👤✨

A modern and clean **social media profile screen UI** built with Flutter.

This project focuses on creating a polished profile experience with user information, profile statistics, action buttons, and a clean responsive layout.

## ✨ Features

- 👤 Modern social media profile screen UI
- 🎨 Clean and minimal design
- 📊 Profile statistics and user information
- ➕ Follow/action button interface
- 🖼️ Profile and content sections
- 🧩 Reusable Flutter widgets
- 📱 Responsive layout
- ⚡ Lightweight and fast UI
- 🎯 Clean and organized code

## 🛠️ Built With

- **Flutter 3.47.2**
- **Dart**

## 📋 Requirements

- Flutter **3.47.2** or compatible version
- Dart SDK included with Flutter
- Android Studio or VS Code
- Xcode for iOS development

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Social-Media-Profile-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Social-Media-Profile-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
